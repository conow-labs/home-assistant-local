Conow Local

A local Modbus RTU/TCP integration that connects CONOW balcony-solar storage devices to Home Assistant.

Version comparison: v1 and v2

Integration 2.5.0. The v2 register map was finalized on November 4, 2026; v1.0 was released on July 16, 2026.

Both register maps share a single parser and entity model; only the data differs. For each entry, exactly one map is loaded and polled.

How to use the panel

The procedure covers the complete workflow from device preparation to a confirmed write; demonstration cards play automatically.

1

Prepare the device in the Conow app

In the CONOW app, navigate to Devices → target device → Modbus Service. Enable Modbus TCP or Modbus RTU according to the connection in use, and verify Slave ID 0xA0 and port 502. Dynamic Auth Code must display “Verified”; select Refresh if it does not.

Add the integration in Home Assistant

Navigate to Settings → Devices & services → Add integration → Conow Local, and select the connection type that matches the hardware. The form below lists the corresponding fields and default values. After submission, the entry appears under Devices & services; if the attempt fails, refer to the Errors tab.

7 Write sequence

Every submission follows the same sequence.

1

Validate

Each writable register is validated against its live limits and dependencies.

2

Merge

Contiguous registers are merged into a single atomic FC 0x10 frame; groups with gaps fall back to consecutive FC 0x06 writes.

3

Read back

The device state is read back immediately; the panel does not wait for the next polling cycle.

FC 0x10 Slave 0xA0 Registers 10100–10107 → one frame → read back

Prerequisites

Prerequisites for a working panel.

✓Turn on “Enable External Control / ModBus RTU” in the Conow app (RTU and adapter links).
✓Direct TCP needs the 8-character hex verification code shown by the machine.
✓Slave 160 (0xA0); RTU serial 38400 8N1; TCP port 502.
✓Only one client may hold the device at a time.
✓Reload the integration after changing connection settings.
✓The panel is in the sidebar and at /conow-local-panel.

Error scenarios and messages

The integration reports the specific cause rather than a generic failure. The following messages correspond to the user interface.

EX 5

The verification code is stale

The device asks for a manual refresh: the verification code is no longer valid and Modbus I/O has stopped. Update it in Settings → Devices & services → Conow Local → Configure.

EX 6

RTU external control is off

The device's RTU external-control switch is off. Open the Conow app, go to the device panel and turn on “Enable External Control / ModBus RTU”, then reload the integration; polling has stopped.
